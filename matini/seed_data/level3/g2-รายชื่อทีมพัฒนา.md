# บทบาทในทีมพัฒนา

อัปเดต มิถุนายน 2569

| บทบาท | ผู้รับผิดชอบ | หน้าที่ |
|---|---|---|
| ผู้พัฒนาระบบ | นักพัฒนา A | เขียนโค้ดและเชื่อมต่อ Ollama |
| ผู้ดูแลเซิร์ฟเวอร์ | นักพัฒนา B | ดูแลเครื่อง สำรองข้อมูล |
| อาจารย์ที่ปรึกษา | อาจารย์ประจำโครงการ | ให้คำแนะนำทั่วไป |

## สิ่งที่ยังไม่ได้กำหนด

- ยังไม่มีผู้รับผิดชอบต่อผลลัพธ์หรือคำตอบที่ผิดพลาดของระบบ
- ยังไม่มีช่องทางร้องเรียนสำหรับนักศึกษา
- ยังไม่มีขั้นตอนเมื่อเกิดเหตุ ผู้ใช้ที่พบปัญหาต้องติดต่อทีมพัฒนาเอง
